
# C Programming Practice 🚀

This repository contains my daily practice projects to master C language fundamentals (Variables, I/O, Conditions, and Switch-Case).

---

## 📂 Projects List

### 1. 🍎 Fruit Store Calculator
* **File:** `fruit_store.c`
* **Description:** A simple fruit market store menu that calculates the total price based on the selected fruit and the input weight in kilograms.
* **Concepts Used:** `switch-case`, `float` variables, basic arithmetic operations, and user input/output (`scanf` / `printf`).

### 2. 🎓 Student Grade Calculator
* **File:** `student_grade_calculator.c`
* **Description:** Calculates a student's total marks, average, and assigns a final grade based on performance.
* **Concepts Used:** `if / else if` conditions, variable calculations, and string handling.


### 3. 🅿️ Smart Parking Fee Calculator

A simple C program designed to calculate parking fees based on the type of vehicle and the duration of parking (in hours).

---

## 🚀 Features
* **Vehicle Selection:** Choose between Motorcycle, Car, or Truck.
* **Dynamic Fee Calculation:** Computes the total parking cost based on hourly rates.
* **Input Validation:** Handles invalid vehicle options and non-positive hours.
